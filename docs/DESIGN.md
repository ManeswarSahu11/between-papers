# Interface direction

Reference review: 8 November 2026.

[ChatPDF](https://www.chatpdf.com/) and [Smallpdf AI PDF](https://smallpdf.com/ai-pdf)
were reviewed as primary product references. Pagewise uses a prominent upload
area and keeps secondary guidance separate from the main task. It does not
claim their editing, image recognition, citation or account features.

The Pagewise interface uses a purple accent, a document/book brand mark,
rounded white form surfaces and a larger file drop zone. Native inputs and
keyboard navigation are preserved. Existing shared-library, OCR and answer
limitations remain visible. No usage statistics or testimonials are invented.
